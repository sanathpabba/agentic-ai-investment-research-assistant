EXECUTIVE SUMMARY
================================================================================

This project demonstrates a production-ready agentic AI system for investment
research and portfolio analytics. It showcases advanced AI agent architecture,
tool-calling patterns, workflow orchestration, and LLMOps best practices.

KEY INNOVATION:
Evolution from single-prompt LLM applications to autonomous multi-step agent
systems capable of goal-oriented reasoning, dynamic tool selection, and
self-directed execution.

EXAMPLE USE CASES
================================================================================

1. Portfolio Risk Analysis
   Query: "Calculate my portfolio's Sharpe ratio and compare to S&P 500"
   Result: Multi-step analysis with specific metrics and comparison

2. Investment Screening
   Query: "Find tech stocks with P/E < 25, market cap > $10B"
   Result: Filtered list with analysis and rankings

3. Stress Testing
   Query: "Stress test my portfolio against 20% market crash"
   Result: Projected impact with recommendations

4. Allocation Analysis
   Query: "Show my sector allocation and suggest rebalancing"
   Result: Current allocation with optimization suggestions

5. Multi-Step Research
   Query: "Analyze my tech holdings, compare to QQQ, and calculate tracking error"
   Result: Comprehensive analysis coordinating multiple tools

GETTING STARTED
================================================================================

Quick Start (5 minutes):

1. Install Dependencies:
   $ cd project1
   $ python -m venv venv
   $ source venv/bin/activate
   $ pip install -r requirements.txt

2. Configure Environment:
   $ cp .env.example .env
   $ # Edit .env with your OPENAI_API_KEY

3. Run Example:
   $ python examples/basic_usage.py
